#

### ℹ️ О программе

Мини-утилита создана для тех, кто часто работает с изображениями, чертежами и фотографиями. Часто возникают ситуации, когда нужно уменьшить разрешение, растянуть, сжать, подкорректировать либо обрезать картинку.

Чтобы не открывать тяжелые редакторы для выполнения таких простых операций и был разработан IMGToolBox.

> Множество полезных функций в легкой упаковке.

#

### 🧩 Устройство

IMGToolBox использует популярные утилиты для редактирования изображений: pingo.exe, cwebp.exe и dwebp.exe

Нативный код C# делает работу с внутренними утилитами максимально быстрой.

> Скорость обработки ничем искусственно не ограничивается — используется полная мощность ПК.
